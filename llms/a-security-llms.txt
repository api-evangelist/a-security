# A Security

> A Security (Ⓐ) is an Israeli-founded cybersecurity company building an autonomous offensive security and remediation platform. It continuously discovers real attack paths inside an organization, validates whether they can actually be exploited, and helps close them before adversaries chain vulnerabilities into a breach — operating at machine speed to keep pace with AI-enabled attackers. The company emerged from stealth in June 2026 with $37M led by Lightspeed Venture Partners and Cyberstarts. Founded by Yossi Torati (CEO), Omer Gull (CPO), and Yuval Itzchakov (CTO). Maintains SOC 2 and ISO 27001. A Security has no public developer API, SDK, or documentation surface at this time.
